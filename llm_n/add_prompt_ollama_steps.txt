Steps:
1. Open PowerShell or Terminal.
2. Navigate to the project root directory.
3. Verify Ollama is installed by running: ollama --version.
4. Run: ollama pull mistral to ensure the Mistral model is available.
5. Run: ollama run mistral --prompt "can you add like this prompt" --format text to generate steps.
6. Copy the generated output from the Terminal.
7. Open the application's Prompt Results or Prompt Editor page.
8. Click Add Steps or Edit Steps for the new instruction.
9. Paste the generated output into the Steps input field.
10. Click Save to attach the generated steps to the instruction.
11. Verify the instruction displays the pasted steps in the prompt list or details view.
